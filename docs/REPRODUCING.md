# Reproducing the paper results

The companion data archive will accompany publication. The feature test suite
can be run using the inputs already included in this repository.

Extract the code and companion data archives into the same parent directory;
both use `Gromacs_CPM/` as their top-level directory. If using a Git clone,
overlay the data archive's `Gromacs_CPM/tests/` onto the clone's `tests/` so
that code and data share one `tests/paper2026/` tree. The code repository alone
contains the runnable feature suite, but not the saved paper datasets.

Install Python with NumPy, SciPy and Matplotlib. The commands below use saved
analysis data and do not launch MD simulations or require a GPU. Analyses that
re-extract observables from GROMACS trajectories additionally require
`GMX_BIN` pointing to a built executable. For building and running the feature
suite, see [the user guide](CPM_USER_GUIDE.md#testing-your-build).

All paper-specific tests, inputs and analyses are under
[`tests/paper2026/`](../tests/paper2026/README.md). Shared system inputs are in
`inputs/slab/` (code archive) and `inputs/slit/` (data archive); the runnable
feature suite is in `cpm_testsuite/`.

Run the analyses in a working copy: several scripts overwrite their generated
summaries or figures beside their inputs. The first command writes a JSON audit
of the saved numerical evidence; the subsequent commands regenerate protocol
summaries, compare CPU/GPU charges and draw the CNT figure.

From the release root:

```bash
python tests/paper2026/audit_final_numbers.py --data tests/paper2026 --output numerical-results.json
python tests/paper2026/timedep/cv5/analyze_cv5.py
python tests/paper2026/timedep/gcd_cutoff/analyze_gcdc.py
python tests/paper2026/eis/analyze_eis.py
python tests/paper2026/gpuval3/compare_gpuval3.py --no-write
python tests/paper2026/cnt_pair/fig_treatments_paper.py
```

The main figure scripts under `tests/paper2026/figures/` are:

| Figure | Script |
|---|---|
| 2: validation | `fig_validation_paper.py` |
| 3: solver comparison | `fig_fiveway_paper.py` |
| 4: time-dependent protocols | `fig_apps_v2_paper.py` |
| 5: impedance | `fig_eis_main_paper.py` |
| 6: Thomas–Fermi electrodes | `fig_tf_paper.py` |

Run each with Python, for example
`python tests/paper2026/figures/fig_validation_paper.py`.
Figure 7 is generated by the CNT command above. The SI figures use
`tests/paper2026/figures/fig_flex.py` and
`tests/paper2026/figures/fig_gpu_validation_paper.py`.
For the overview and TOC artwork, run `fig_features.py`, then compile
`fig_overview_paper.tex` and `fig_toc.tex` with pdfLaTeX from that same figure
directory (requires the standalone and TikZ LaTeX packages).

The data archive contains the completed trajectories, energies, input TPRs and
charge records for all 16 CNT conditions. Their means and sampling windows are
in `tests/paper2026/cnt_pair/results.json`. Other campaigns provide the saved
charge/voltage traces, profiles, reference charges and timing summaries used by
the paper. This is an analysis dataset, not a claim that every historical MD
trajectory or benchmark binary is included. Historical performance records
describe their original runs.

The results use within-trajectory block standard errors or temporal standard
deviations as specified in the paper. They do not replace independent replica
uncertainties or establish equilibrium for slowly relaxing systems.
